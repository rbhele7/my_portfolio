# Riya Bhele | Developer Portfolio

A modern, responsive personal portfolio built with React, Vite and Tailwind CSS to showcase my projects, technical skills, academic journey and competitive programming achievements.

## ✨ Features

- **Modern UI:** Dark-themed interface with gradient accents, glassmorphism and responsive layouts.
- **Responsive Design:** Optimized for desktop, tablet and mobile devices.
- **Smooth Animations:** Interactive animations powered by Framer Motion.
- **Projects Showcase:** Highlights selected development projects and their tech stacks.
- **Technical Skills:** Organized overview of programming languages, frameworks, tools and CS fundamentals.
- **Achievements:** Competitive programming profiles and milestones.
- **Education:** Academic background and relevant coursework.
- **Contact Section:** Contact links and an email-based message form.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite, usually:

```text
http://localhost:5173
```

## 🏗️ Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

The production-ready files are generated inside the `dist/` directory.
