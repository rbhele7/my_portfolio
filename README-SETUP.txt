FIXED PORTFOLIO SETUP
1. Copy the src/components and other src files into your existing Desktop/portfolio project.
2. Keep your existing src/assets/hero.png because Hero.jsx imports it.
3. Replace package.json and vite.config.js with these included versions.
4. From the project folder run: npm install
5. Start using: npm run dev
6. Open the exact localhost URL printed by Vite (usually http://localhost:5173).
Do not use VS Code Live Server or open index.html directly.
